🎉 Initial Release: Local Helper v0.1.0

Open-source, cross-platform alternative to Claude Cowork

## What is Local Helper?

Local Helper is an autonomous AI assistant for file management and 
productivity tasks using Claude API. Unlike Claude Cowork, it works 
on all platforms and is fully open source.

## ✨ Features

### Core Capabilities
- 🤖 Autonomous task execution with natural language
- 📁 Complete file management (read, write, move, copy, delete, organize)
- 📄 Multi-format document processing (PDF, Excel, Word, CSV, JSON)
- 📊 Automated report generation
- 🔍 Smart file search (name and content)
- ⚡ Batch operations

### Safety & Security
- 🔒 Workspace sandboxing
- 💾 Automatic backups before modifications
- ✅ Path validation (prevents directory traversal)
- 📝 Complete operation logging
- 🛡️ File size limits

### User Experience
- 🎨 Beautiful CLI with Rich library
- 📊 Real-time progress tracking
- 💬 Interactive prompts
- 📖 Comprehensive help system
- 🎯 Clear error messages
